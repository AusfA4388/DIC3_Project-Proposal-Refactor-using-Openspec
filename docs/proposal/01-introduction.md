## 1.1 General：短線交易的普及與困境

短線當沖已成為台灣股市的主要交易型態之一。根據證交所統計，2025 年台股當沖成交值超過 36 兆元，占全年成交值 32.77%，平均每日約有 15 萬戶進行當沖 [1]；2026 年 11 月，上市市場單日當沖占比更一度達到 45.22% [2]。然而，參與者眾不代表獲利者眾。Barber 等人分析台灣證交所 1992–2006 年的完整交易紀錄，發現典型年度中只有約 13% 的當沖者在扣除手續費與交易稅後獲利，能夠持續獲利者不到 1% [3]；巴西期貨市場的研究也發現，持續當沖超過 300 天的交易者有 97% 虧損 [4]。

## 1.2 However：非專業交易者面對的三項負擔

短線決策要在數秒到數分鐘內完成，非專業交易者必須同時處理三件事：(1) **結構判斷**：在大量 K 棒中辨識支撐壓力與供需區；(2) **機率判斷**：評估價格在這個位置反彈或突破的可能性；(3) **風險計算**：在進場前定義停損位置、計算風險報酬比與倉位。這三件事分別需要圖表經驗、統計能力與紀律，在高速盤面與恐懼、貪婪等情緒干擾下，幾乎不可能同時做好。結果是交易者常在錯誤的位置進場，或在沒有明確停損的情況下擴大虧損。

## 1.3 In literature：現有技術的發展

既有研究從三個方向嘗試解決上述問題。第一，**機器學習預測**：以技術指標訓練 XGBoost 等分類器預測價格方向 [9]，或將支撐壓力距離作為特徵，提升停利命中的精確度 [7]。第二，**支撐壓力自動化**：以 Swing High/Low、注意力模型與分群演算法自動找出支撐壓力水平 [7], [8]。第三，**LLM 交易代理人**：以多個 LLM 角色模擬交易團隊分工 [10]，或以視覺語言模型讀取 K 線圖 [11]；近期也開始出現讓 LLM 負責情境、確定性模組負責數值的混合架構 [13], [14]。

## 1.4 Judgement：各方法的侷限

這三類方法各解決了一部分問題，但都留下缺口。技術指標本身具有滯後性，僅以指標訓練的 ML 模型不知道「價格現在位於哪個結構位置」[9]。支撐壓力演算法多停在畫出水平線，無法評估價格回測時的勝率 [7], [8]。LLM 代理人雖擅長推理，但數值計算與機率估計不可靠 [14]；更重要的是，LLM 可能記得訓練資料中的歷史行情，使回測績效被高估 [16]–[18]，在更長、更廣的測試中，先前報告的 LLM 優勢明顯衰退 [15]。2026 年的綜述也指出，多數代理人系統只聚焦於產生訊號，很少完整處理風險管理 [12]。

## 1.5 Keypoint：本專題的方法與核心貢獻

為此，本專題提出 **Hybrid TPA-Agent**，核心原則是「**讓每個元件只做它最擅長的事**」：確定性演算法負責標記供需區、XGBoost 負責估計勝率、LLM 負責結合價格行為知識做情境推理，最後由確定性風控引擎依勝率與風險報酬比決定是否產出交易設定，並由交易者確認後才執行。本專題預期的貢獻如下：

1. **混合式短線交易代理人架構**：提出結合確定性空間演算法、機器學習與 LLM 推理的四層八模組架構，並明確界定 LLM 不負責數值與空間運算，以降低數值幻覺與回測偏誤的影響（對應 Core C1、C3）。
2. **價格行為知識的程式化**：將供需區、S/R Flip、假突破等價格行為概念轉為可重現的程式規則與結構化特徵，並以 XGBoost 估計突破與反彈勝率（對應 Core C1、C2）。
3. **風險優先的決策流程**：以期望值 E = W×RR − (1−W) 與雙門檻（W ≥ 0.55、RR ≥ 2.0）決定是否出手，並保留人工確認與資料異常時的降級機制（對應 Core C4、C5）。
4. **可複現的開源規格**：以 OpenSpec 規格驅動開發，提供完整的 DESIGN.md、模組規格與可重複驗證的程式碼庫，讓後續開發者能理解、執行並延伸本系統。
